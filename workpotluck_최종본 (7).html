5WORKPOTLUCK ROADMAP

파주시 업무에 맞춘 AI 비서의 현재 구현 단계부터 폐쇄망 행정시스템 연동까지의 발전 계획입니다.

PHASE 01 · 현재

업무 기반 데모 구축

실제 행정업무를 가공한 시나리오와 행정번호 기반 담당업무 매칭 구조를 구현했습니다.

PHASE 02 · 현재

실시간 AI·공개정보 검색

API 키 연동을 통해 담당업무와 공공기관 공개정보를 근거로 답변하는 구조를 적용합니다.

PHASE 03 · 적용 완료

문서·엑셀 자동 파싱

PDF, XLS(X), HWPX, DOCX, TXT, CSV의 본문 추출을 지원하며 스캔 OCR과 HWP 전체 본문으로 확장합니다.

PHASE 04 · 확장

Supabase 다중사용자 DB

부서별 자료를 안전하게 축적하고 실시간으로 공유하는 공동 데이터베이스 구조로 확장합니다.

PHASE 05 · 업무망

Ollama 폐쇄망 LLM

보안과 개인정보 요건을 반영해 외부 API를 폐쇄망 로컬 AI로 대체합니다.

PHASE 06 · 목표

새올 행정시스템 연동

인사정보·조직도를 자동 동기화하고 예산 데이터까지 연결하는 통합 업무환경을 완성합니다.
